| Step 1 — sinkronisasi LMS | Kode dan diagnostik diperbaiki; deployment belum lulus | Retry tiga kali, backoff, timeout, riwayat batch dan pesan ramah diuji dengan server HTTP simulasi. | Step 12 — keamanan transport & header | Implementasi lokal; production acceptance menunggu proxy | Fiber hanya mempercayai header skema dari proxy yang terdaftar; validasi IP/CIDR, redirect 301 ke `PUBLIC_BASE_URL` kanonis, HSTS 1 tahun, CSP, nosniff, frame deny, referrer/permissions policy, dan penghapusan `X-Powered-By` ditambahkan serta diuji. `/health` tetap tersedia untuk probe container internal. Belum bisa menyalakan `FORCE_HTTPS` atau membuktikan grade eksternal tanpa mengetahui IP/CIDR proxy Coolify dan mengubah environment deployment. |
| Step 13 — backup otomatis | Skrip & dokumentasi lokal; restore acceptance terbuka | Backup PostgreSQL sekarang atomik, dicek sebagai arsip dan checksum SHA-256, retensi default 365 hari. Ditambahkan verifikasi backup dan restore-drill yang hanya membuat database baru bernama `cbt_restore_drill_*`, menolak target yang ada, dan tidak menghapus apa pun. Jadwal Coolify, volume backup persisten, serta satu restore nyata ke DB uji belum dikonfigurasi/dijalankan; tidak ada database lokal disposable dan tidak menyentuh produksi. Sintaks skrip shell belum dapat dieksekusi pada host ini (PowerShell tanpa POSIX shell, Docker, atau WSL). |
| Step 14 — template awal 15 tipe soal | Implementasi; E2E lulus | Setiap jenis soal kini memulai dengan contoh prompt dan konfigurasi/kunci yang relevan, termasuk opsi pilihan, pasangan/kisi, jawaban singkat, rubrik uraian, dan batas berkas. Saat tutor mengganti tipe, contoh diperbarui hanya selama prompt masih contoh awal; teks yang sudah ditulis tutor dipertahankan. E2E memeriksa seluruh 15 tipe dan konfigurasi inti; soal hasil tes memakai API mock. |
| Step 15 — impor soal | Implementasi; unit/E2E lulus | Tersedia template CSV/XLSX/DOCX, endpoint file contoh 20 soal, parser tervalidasi dan laporan impor parsial per baris. E2E unduh template/impor memakai mock API; belum membuktikan impor ke DB PostgreSQL produksi. |
| Step 16 — media drag-and-drop | Implementasi lokal; verifikasi upload UI lulus | Unggah stimulus dan media opsi tersedia lewat drop/pilih file, gambar besar dikompresi browser ke WebP, server memvalidasi signature, batas 5 MB, menyimpan privat, dan pratinjau siswa memakai URL terlindungi. Tes Go menolak format/ekstensi tak cocok dan file di atas 5 MB; E2E unggah gambar PNG besar, verifikasi request terkompresi, alt text, penyimpanan dan preview. Audio/video diterima bila sudah ≤5 MB, tetapi browser belum melakukan transcoding otomatis untuk keduanya; kondisi ini dicatat sebagai keterbatasan. Belum ada upload real ke volume Coolify. |
| Step 17 — duplikasi dan template paket | Implementasi; unit/E2E mock lulus | Disediakan Ujian Semester 40 PG + 5 esai (90 menit), Try-out 20 PG (60 menit), dan Kuis 10 PG (30 menit). Duplikasi paket membuat soal draf baru dari snapshot, mempertahankan isi/kunci, tetapi mengosongkan kelas, jadwal, kode akses, dan peserta untuk mencegah akses tak sengaja. | Step 18 — folder & tag | Implementasi lokal; E2E lulus | Bank Soal mendukung folder hierarkis mapel→topik, pindah soal draf dengan revision/QuestionVersion dan audit, filter folder/tag serentak, serta tag multi-pilih visual. Tes unit memeriksa normalisasi serta pencocokan tag persis; E2E memeriksa pembuatan folder, pemindahan, dan filter. Endpoint/migrasi PostgreSQL aktual belum diuji pada DB disposable. |
